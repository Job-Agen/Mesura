# Merchant logos

Shown next to cards locked to a merchant and in the payment history, to identify the merchant. Each file is
the brand's own icon, normalised to 192 × 192 PNG (downloaded 16 Oct 2026).

| File | Source |
| --- | --- |
| `canva.png` | canva.com site icon |
| `meta.png` | meta.com site icon |
| `google.png` | google.com site icon |
| `openai.png` | openai.com site icon |
| `netflix.png` | Netflix "N" from Simple Icons (sourced from brand.netflix.com), in Netflix red #E50914 |
| `amazon.png` | amazon.com site icon (only 48 px was reachable: replace with the brand kit's) |

These are the merchants' trademarks, used only to name the merchant; Mesura is not affiliated with them. Before
the public launch, check each brand's guidelines (Canva, OpenAI and Amazon asked Simple Icons to remove their
logos) and replace or remove any file a brand does not allow.
